# GenericSpecimenManager (Slicer extension)

This folder is the Slicer extension; the module Slicer loads is the `GenericSpecimenManager/` folder inside it (add
**that** folder as an additional module path - see *Quick start* in the [repository README](../README.md)).

The idea, the feature list and the documentation index are in the [repository README](../README.md). Where to go next:

| I want to... | read |
|---|---|
| set up my first study, step by step | [howto/first-study.md](../howto/first-study.md) |
| understand the module window: specimens, statuses, filters, reset | [docs/main-module.md](../docs/main-module.md) |
| look up a config key | [docs/config-reference.md](../docs/config-reference.md) |
| find my way around the code | [docs/dev/architecture.md](../docs/dev/architecture.md) |

Every field has a tooltip, and the module's **Help** block and the Config Editor's **Help** button open searchable
cheat sheets.
